I'm Pablo Madrigal, a systems engineer and Lead Frontend Architect in Costa Rica. I design the component
systems, tests and pipelines that let product teams ship fast without breaking things.

I've built with Vue since 2019: first full stack on .NET Core APIs, then at a product company, where I grew
from frontend consultant to leading its frontend architecture. I work in Spanish (native) and English
(advanced).

## Beyond Vue

Vue is where I've gone deepest. It has never been the limit. Along the way I've shipped a Node.js application,
built full-stack applications on .NET Core, debugged Java systems and written concurrent C with threads.

Most of what I use today I taught myself, usually because a problem needed it. This site is the current
lesson: a token pipeline built from scratch, contrast tests that run on every change, and a deploy that
nobody has to remember.

## How I work

- **Choose the tool the problem calls for.** The right technology is the one the problem needs, even when it
  isn't the one I know best. Learning it is part of the job.
- **Design the system, not the screen.** A well-designed component library makes the hundredth screen cheaper
  than the tenth.
- **Make quality automatic.** Tests, accessibility checks and performance budgets run on every change, so
  standards hold without anyone having to remember them.
- **Write decisions down.** The reasoning behind an architecture outlives the people who chose it. This site
  keeps its own in [docs/decisions](https://github.com/pmadrigal95/crease-pattern/tree/main/docs/decisions).
- **Leave every release better than the last.** That goes for the products I build and for me.
