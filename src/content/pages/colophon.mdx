## Architecture

- **[Astro](https://astro.build/)** renders every page to static HTML at build time. A page ships no framework
  JavaScript unless one of its components needs it.
- **TypeScript** in its strictest configuration, from content schemas to components.

## Design system

- **One system, three identities.** Contour lines, Basalt & glacier and Washi & asagi share the same semantic
  tokens. Only the primitive colors change.
- Tokens are authored in the [DTCG format](https://www.designtokens.org/) and compiled to CSS at build time.
- **Contrast is tested.** A unit test checks every text and interface color against WCAG 2.2 AA, in all three
  identities, in light and dark.
- Type is set in **Schibsted Grotesk** and **JetBrains Mono**, with **Newsreader** for Precrease headlines, all
  self-hosted.
- Behind the home hero, each identity has its own surface: contour lines, basalt joints or washi fibers. A
  script draws each one as a seamless SVG tile of a few kilobytes, using an AI image only as a reference.

## The portrait

The portrait on [About](/about) is one real photo, untouched by generative AI, shown two ways.

- **The interface** is the photo itself. The duotone is plain CSS: a grayscale image blended with the active
  identity's colors and cut to a silhouette mask, so it follows every identity and theme without extra files.
- **The architecture** is the same face as contour lines. A depth map of the photo comes from
  [Depth Anything V2 Small](https://github.com/DepthAnything/Depth-Anything-V2) (Apache 2.0), run once on
  my machine, and a marching-squares script traces it into an 11 KB SVG.
- Drag the handle, or focus it and use the arrow keys, to move the fold.

## Quality gates

A change can't merge until it passes formatting, linting, type checks, unit tests, an axe accessibility scan
in every identity and theme, and Lighthouse budgets:

| Budget                   | Threshold    |
| ------------------------ | ------------ |
| Performance              | 95 or higher |
| Accessibility            | 100          |
| Best practices           | 100          |
| SEO                      | 100          |
| Largest Contentful Paint | under 1.8 s  |
| Cumulative Layout Shift  | under 0.05   |

## Hosting

Static files on **Cloudflare Workers**, deployed automatically from the `main` branch.
