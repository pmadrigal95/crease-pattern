# 0002 · Clean-room design system

Status: accepted · 2026-10-23

## Context

This repository is the public showcase of the author's engineering practice. Its value depends on
every file having a clear, original provenance.

## Decision

- This repository starts from an empty history and contains only code written for it.
- No files, component names, folder conventions or patterns are copied from other codebases.
- Tokens, palette, typography and component names are original to this project.

## Consequences

- The provenance of every file is clear from the git history.
- Patterns are reimplemented from first principles, documented in these ADRs.
